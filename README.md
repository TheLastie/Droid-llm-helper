# OfflineRef

Офлайн-помощник-справочник (LLM на устройстве, база знаний с эмбеддингами,
работа без сети). Целевое устройство: Nothing Phone 2a, 12 ГБ ОЗУ, Android 16.

## Текущий статус
- Шаг 1 (B1): конфигурационный каркас + самодиагностика. Экран должен
  показать "B1 OK". Ничего больше - это намеренно (бисекция, правило 4.5).

## Дорожная карта
1. [x] B1: каркас, signing, CI, dex-проверка, аварийный экран
2. [ ] UI чата (Compose) + экран "Первый запуск" (скачивание модели, sha256)
3. [ ] LlamaEngine: llama.cpp JNI, загрузка GGUF, генерация, стриминг
4. [ ] База знаний: импорт .md/.txt/.pdf, чанкование
5. [ ] Эмбеддинги: ONNX Runtime Mobile + multilingual-e5-small, sqlite-vec
6. [ ] Retriever: гибрид векторный + FTS5, пороги, fallback с пометкой
7. [ ] Карточки быстрых тем, настройки, история
8. [ ] Авитесты: авиарежим, 20 вопросов по базе + 10 "мимо"

## Правила работы (из playbook, кратко)
- CI - единственный источник APK. После push: git ls-remote origin main
  должен совпадать с локальным HEAD.
- APK только с уникальными именами (OfflineRef-vN.apk) + sha256sum в таблицу.
- Нативные библиотеки: NDK 27+, onnxruntime-android >= 1.20 (16KB-страницы
  Android 15/16!). Добавляем на шаге 3/5 - не раньше.
- extractNativeLibs=true, abiFilters arm64-v8a, minSdk 26, targetSdk 34.

## Локальная разработка
1. Клонируйте репозиторий.
2. Откройте в Android Studio - она сама создаст gradle wrapper при первой
   синхронизации (wrapper в репо не храним, CI собирает через setup-gradle).
3. Сборка через CI: push в main -> Actions -> артефакт OfflineRef-vN.
