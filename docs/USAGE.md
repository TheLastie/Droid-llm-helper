# Руководство пользователя OfflineRef

## Первый запуск

1. Установите APK, откройте. Увидите статус загрузки модели (~1,9 ГБ, один раз).
2. После загрузки появится чат. База знаний уже внутри (19 документов).
3. Серые строки в чате — служебная диагностика (можно игнорировать).

## Режимы ответа

### Обычный (по умолчанию)
Модель отвечает **строго по базе знаний**. Под ответом — источники:
`Источники: 11_справочник_грибника.txt (фрагмент 568/1522, стр. 38)`

Если по теме найден документ с иллюстрациями — появляется кнопка:
**«📷 11_справочник_грибника.txt, стр. 38 (показать страницу)»** — нажмите, чтобы увидеть
оригинальную страницу книги с фотографией.

### Дословный (мгновенный, без модели)
Включите галочку «Дословно» над полем ввода **или** начните вопрос с восклицательного знака:
`!мухомор` — приложение мгновенно покажет до 3 фрагментов исходного текста.
Ноль галлюцинаций, работает даже при разряженном состоянии модели.

### Общий режим (fallback)
Если в базе ничего не найдено, ответ помечается «(общие знания модели)» — это знания самой
нейросети, им доверяйте меньше, чем ответам со ссылками на источники.

## База знаний

Кнопка «БАЗА ЗНАНИЙ» — экран управления:
- **«+ Импортировать документ»** — добавьте свой .txt/.md или PDF (PDF со сканами
  распознаётся на устройстве, импорт большой книги занимает 5–15 минут).
- **«Восстановить из бэкапа»** — вернёт базу, если она повредится.
- «Удалить» — убрать документ.

После каждого импорта бэкап обновляется автоматически.

## Сохранение чата

- «Сохранить чат» — запись истории в файл (`Android/data/com.offlineref/files/chat_history.txt`).
- «Очистить» — очистить экран. При следующем запуске чат восстановится из сохранённого файла.

## Время ответа

| Ситуация | Время |
|---|---|
| Первый вопрос после запуска | загрузка модели ~10–20 с + ответ |
| Обычный вопрос | ~40–60 с |
| Дословный режим | < 1 с |

Если ответ дольше 60 с — телефон перегрет; дайте остыть пару минут.

## Ограничения (честно)

- Поиск понимает русские падежи и точные термины, но не перефразы
  («оказать помощь при обмороке» ≠ «потерял сознание») — для таких вопросов
  используйте слова из документов.
- Англоязычный документ русским запросом не находится.
- OCR сканов — распознавание без гарантии идеальной точности; по фотографии
  страницы всегда можно сверить оригинал.
