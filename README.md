# OfflineRef

**Офлайн-справочник с локальной LLM**: ответы строго по вашей базе знаний, без сети, без галлюцинаций по документам. Целевое устройство — Nothing Phone 2a (12 ГБ ОЗУ, Android 16), лимит ответа — 60 секунд.

## Что умеет

- **Чат со справочником** — вопрос → поиск по базе → ответ модели **строго по найденным фрагментам**, со ссылками «Источники: документ (фрагмент N/M, стр. X)».
- **Страницы книг с фотографиями** — кнопка «📷 стр. N» показывает оригинальную страницу (у грибного справочника — фотографии грибов).
- **Дословный режим** — галочка или префикс `!` → текст из базы мгновенно, без модели, ноль галлюцинаций.
- **19 документов из коробки**: первая помощь, аптечка, выживание, ориентирование, авто, дом, документы, стресс + бушкрафт (4 док.) + грибной справочник Семёнова (1577 фрагментов, 468 страниц с иллюстрациями).
- **Сохранение чата** — кнопка «Сохранить чат», история восстанавливается при запуске.
- **Импорт своих документов** — .txt/.md и PDF (со сканами: OCR на устройстве).
- **Полный офлайн** — после установки и первой загрузки модели сеть не нужна.

## Установка

1. Скачайте APK: `https://raw.githubusercontent.com/TheLastie/Droid-llm-helper/apk/OfflineRef-latest.apk`
2. Установите, запустите.
3. При первом запуске приложение скачает модель Qwen2.5-3B (~1,9 ГБ, один раз, нужна сеть) — дальше всё офлайн.
4. База знаний подгружается из APK автоматически (19 документов, ~1577 фрагментов).

## Быстрый тест

| Запрос | Ожидаемый результат |
|---|---|
| `подосиновик` | Ответ из грибного справочника + «📷 стр. …» |
| `!бледная поганка` (дословно) | Мгновенный сырой текст из книги |
| `парацетамол дозировка` | Ответ из аптечки со ссылкой |
| `как выжить в тайге` | Ответ из бушкрафт-документов |
